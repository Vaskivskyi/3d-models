## Printing

The models are designed to be easy to print. The quasi-2D model has a hole for a string to hang it on a Christmas tree or other places.

Prints well with:

- 0.2 mm / 0.2 mm layer height
- 150 mm/s
- no supports, no rafts, no brims

Printed on:

- [Anycubic Kobra 2 Pro](https://amzn.to/4e0Dz7R)

Printed with:

- [eSUN Silk Tri-color PLA](https://amzn.to/41PaaKC)
- [TEQStone 2-color Silk PLA](https://amzn.to/49TMiqQ)
- [GIANTARM Silk PLA](https://amzn.to/41Pf766)
